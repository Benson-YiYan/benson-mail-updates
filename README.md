# Legacy update compatibility / 旧版更新兼容入口

This repository keeps the original update address working for older Email Assistant installations.

All source code, installers, releases, documentation and issues are maintained at:
https://github.com/Benson-YiYan/benson-mail-assistant

`manifest.json` is synchronized automatically by the update server. It points to the same current installers as the main project. Do not replace it with a web page or a URL string: old clients require the full JSON manifest.

本仓库仅用于兼容旧版邮件小秘书的更新地址。源码、安装程序、Releases、文档与问题反馈统一在上面的主仓库维护。更新服务器自动同步此处的更新清单。

Este repositorio mantiene la dirección de actualización de las versiones antiguas. El código, los instaladores y la documentación se mantienen en el repositorio principal indicado arriba.
